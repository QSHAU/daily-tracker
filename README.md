# Темп

Локальный трекер времени без базы данных и зависимостей.

Запуск: `npm start`, затем откройте http://localhost:3000.

Начать создаёт сессию. Остановить закрывает основной отрезок и запускает паузу. Продолжить закрывает паузу и создаёт основной отрезок. Закончить завершает сессию. Ошибочный отрезок удаляется кнопкой с корзиной (два нажатия): его время забирает предыдущий отрезок, а если удалён первый — следующий. Удаление единственного отрезка удаляет всю сессию. Кнопка с карандашом (или клик по длительности отрезка) открывает правку времени. Длительность меняется кнопками ±5 мин или вводом часов и минут; она связана с началом и концом, а верхняя граница считается так, чтобы отрезок не залез на следующий отрезок, следующую сессию или в будущее. Кроме того: у завершённого отрезка меняются начало и конец (соседний отрезок подстраивается, чтобы не было пустот и наложений), а у идущего можно указать «Остановился в …» — с этого момента начнётся перерыв (или работа, если шёл перерыв), либо сессию можно закончить задним числом. Таймер (карточка справа) задаёт длительность работы и перерыва: отсчёт идёт от начала текущего отрезка, по истечении звучит звон, а с опцией автопереключения работа и перерыв сменяют друг друга сами — точно в момент сигнала. Звон синтезируется в браузере и планируется заранее, поэтому звучит вовремя и в фоновой вкладке; после перезагрузки страницы браузер разрешит звук только после любого клика по ней. После перерыва «Продолжить» возвращает занятие, которое было до него. Тема (светлая/тёмная) переключается кнопкой в шапке и запоминается; по умолчанию берётся из системы. Категории меняются у каждого отрезка, включая завершённые сессии. Циферблат показывает реальные часы; если сессия длиннее 12 часов, каждый следующий круг ложится поверх предыдущего и окрашивается темнее. Статистика распределяет время по календарным дням и месяцам в часовом поясе браузера.

Данные сохраняются в localStorage этого браузера и адреса. Отсчёт продолжается при закрытой вкладке, пока вы не завершите сессию. Очистка данных браузера удаляет историю; JSON-экспорт позволяет сохранить копию. Для стабильного хранения пользуйтесь одним адресом, например http://localhost:3000. Интернет нужен только для необязательного шрифта; без него используется системный шрифт.
